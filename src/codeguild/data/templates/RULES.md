# Development Rules

## General
- Reuse existing code; do not duplicate logic.
- Keep functions small. Do not modify unrelated files.

## Before coding
- Read PRD.md, ARCHITECTURE.md and TASKS.md.
- Inspect the existing implementation.

## Testing
- Add tests for important functionality; run them; fix failures before continuing.

## Security
- Never commit secrets. Validate user input.

## Git
- Small commits with descriptive messages.
